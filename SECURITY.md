# Security Policy

## Supported Versions

Security fixes are made on the `main` branch and included in the next app release. Older releases are not patched separately, so please update to the latest version of the app.

## Reporting a Vulnerability

**Do not report security vulnerabilities through public GitHub issues, pull requests or discussions.**

Report them privately through GitHub's private vulnerability reporting:

1. Go to the [Security tab](https://github.com/Sunbird-Spark/sunbird-spark-mobile-app/security) of this repository.
2. Click **Report a vulnerability**.
3. Fill in the advisory form.

Please include as much of the following as you can:

- The type of issue (for example credential exposure, insecure storage, injection, or an insecure WebView configuration)
- The affected file paths, components or app screens
- The app version, platform (Android/iOS) and device or OS version
- Step-by-step instructions to reproduce the issue
- Proof-of-concept code or screenshots, if available
- The impact, and how an attacker could exploit the issue

## What to Expect

- The maintainers will acknowledge your report and keep you updated on the fix.
- Please give the maintainers a reasonable amount of time to fix the issue and ship a release before disclosing it publicly.
- Once a fix is released, a GitHub Security Advisory will be published, and you will be credited unless you ask not to be.

## Dependency Vulnerabilities

Vulnerabilities in third-party dependencies are tracked through Dependabot alerts and the dependency graph. If a vulnerable dependency affects this app in a way that isn't already reported, please follow the process above.
